# 기록장

기록 도구. 브라우저 안에 자동 저장되며 서버로 아무것도 보내지 않습니다.

운동 · 생각 · 책 밑줄 · 여행 네 가지를 적어둡니다.

## 운동

부위를 고르면 그 부위의 운동 목록이 나옵니다.
운동을 누르면 칸이 열리고, 방금 든 무게와 횟수를 한 세트씩 쌓아 넣습니다.
운동을 열면 지난번 무게와 횟수가 미리 들어가 있으므로,
그대로 하셨다면 **기록**만 누르면 됩니다.
부위마다 운동한 날과 누적 세트 수가 함께 표시됩니다.

## 폰에서 쓰기

1. GitHub Pages 주소를 폰 크롬으로 엽니다
2. 크롬 메뉴(⋮) → **홈 화면에 추가**
3. 생긴 아이콘으로 바로 열립니다

## 백업

가끔 맨 아래 **파일로 내보내기**를 눌러 JSON 파일을 받아두세요.
폰을 바꾸거나 브라우저 데이터를 지웠을 때
**파일에서 불러오기 → 복원** 으로 되살릴 수 있습니다.

## 주의

기록은 그 브라우저에만 저장됩니다.
PC 크롬과 폰 크롬은 서로 다른 저장소이므로 기록이 공유되지 않습니다.
옮기려면 내보내기 파일을 쓰세요.
