# 한 달, 하나 끝내기

기록 도구. 브라우저 안에 자동 저장되며 서버로 아무것도 보내지 않습니다.

## 폰에서 쓰기

1. GitHub Pages 주소를 폰 크롬으로 엽니다
2. 크롬 메뉴(⋮) → **홈 화면에 추가**
3. 생긴 아이콘으로 바로 열립니다

## 백업

가끔 맨 아래 **파일로 내보내기**를 눌러 JSON 파일을 받아두세요.
폰을 바꾸거나 브라우저 데이터를 지웠을 때
**파일에서 불러오기 → 복원** 으로 되살릴 수 있습니다.

## 주의

기록은 그 브라우저에만 저장됩니다.
PC 크롬과 폰 크롬은 서로 다른 저장소이므로 기록이 공유되지 않습니다.
옮기려면 내보내기 파일을 쓰세요.
