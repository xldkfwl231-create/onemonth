# 나만의 슬라임 만들기 — 설계 (옛 이름: 나만의 고양이 찾기)

> 나를 닮은 고양이 한 마리를 매일 거짓 없이 관찰하면, 관찰이 쌓이는 대로 고양이가 자기에게 맞는 자리로 조금씩 옮겨 가는 앱.

작성: 2026-09-30 · 상태: **방향 바뀜 (2026-10-10)** — 아래 3장(하루 일과)·5장(척도)·6장(자리 계산)·7장(시간대 질문)은 더 이상 쓰지 않습니다. 새 흐름은 다음과 같고, 요약 구조가 정해지면 이 문서를 다시 씁니다.

> **새 흐름:** ① 나에 대한 생각을 아무 때나 적는다 ② 책·생각에 대해 내가 먼저 묻고 고양이와 토론한다 ③ 앱에서 오간 모든 대화를 기록으로 남긴다 ④ 고양이는 홈 화면에서 쌓인 것을 **요약**한다(인용 + 반복 패턴 + 되묻기, 결론 없음). 척도와 자리는 미리 정하지 않고, 요약에서 반복되는 것이 생기면 그때 만든다. 하루 일과 칸은 1단계에서 만들었다가 2026-10-10에 뺐다. 같은 날 껍질을 고양이에서 **슬라임**(3D, 만지면 출렁임, 가지고 놀면 말풍선)으로 바꿨다. 수집품 개념은 뺐다. 슬라임의 색·투명도·단단함은 나중에 요약이 정한다.

## 1. 배경과 원칙

짐 콜린스의 『어떻게 살아낼 것인가』에 나오는 **버그북**에서 출발한다. 버그북은 자신을 곤충처럼 한 발 떨어져서, 판단 없이, 3인칭으로 관찰해 적는 노트다. 이 앱은 벌레 대신 **고양이**를 관찰 대상으로 삼고, 쌓인 관찰을 **고양이가 있는 장소**로 보여 준다.

지금의 독서 기록장(기록장 · 읽고 남은 것들)을 이 앱으로 바꾼다. 독서는 관찰 영역 중 하나로 남는다.

원칙은 다섯 가지다.

1. **직접 기록이 중심이다.** 사용자가 "난 이랬구나"를 스스로 적는다.
2. **고양이가 때맞춰 묻는다.** 전부 자발 기록에 맡기면 끊기므로, 시간대에 맞는 질문을 고양이가 먼저 건넨다.
3. **거짓 없이, 판단 없이.** 좋은 답도 나쁜 답도 없다. 넘어가도 재촉하지 않는다.
4. **목표는 직업이 아니다.** 적성검사나 진로 추천을 하지 않는다. "내 고양이가 지금 어디에 있는지"를 눈으로 보는 것이 목표다. 검증된 심리검사가 아니라 거울이라는 점을 앱 안에서도 밝힌다.
5. **원문이 기준이다.** 쓴 글과 누른 답은 기기에 그대로 남긴다. AI의 정리는 따로 보관하는 "해석"이고, 언제든 원문에서 다시 계산할 수 있다.

## 2. 기록의 네 갈래

| 갈래 | 내용 | 시작하는 쪽 | 비고 |
|---|---|---|---|
| **책** | 책 → 문장, 질문과 답 | 사용자 | 지금 구조 그대로. 문장과 질문은 책에 묶인다 |
| **생각** | 책과 상관없이 스스로 떠오른 생각 | 사용자 | 책과 완전히 별개로 둔다 |
| **하루** | 기상부터 취침까지의 일과 (3장) | 주로 고양이 | 누르기 위주, 하루에 한 묶음 |
| **순간** | 운동·코딩·게임·쇼츠·사람 등 한 장면 한 줄 | 사용자 또는 고양이 | 기존 "다녀온 자리"(여행)는 장소가 붙은 순간으로 옮긴다 |

모든 순간에는 같은 빠른 표시 세 개가 붙는다(선택).

- **기운:** ↑ 났다 / → 그대로 / ↓ 빠졌다
- **누구와:** 혼자 / 둘이 / 여럿
- **골랐나:** 골랐다 / 어쩌다 보니 / 해야 해서

쇼츠처럼 알고리즘이 골라 준 것은 내용을 적지 않는다. **언제, 왜 켰는지**와 **끄고 난 뒤의 기운**만 신호로 쓴다.

| 때 | 묻는 것 | 답 |

| | 타고 간 것 | 걸어서 / 자전거 / 버스·지하철 / 차 / 재택(건너뜀) |
| | 가는 동안 한 것 | 음악 / 책 / 쇼츠·SNS / 멍 / 생각 정리 |

쉬는 날에는 출근길과 일 칸을 묻지 않고, 대신 "오늘 가장 오래 머문 곳"과 "가장 오래 한 것"을 묻는다.

## 4. 상태와 성향

잠을 못 잔 날 기운이 빠진 것은 취향이 아니라 컨디션이다. 둘을 섞지 않는다.

| | 무엇으로 정해지나 | 화면에서 | 변하는 속도 |
|---|---|---|---|
| **성향** | 길의 느낌, 골랐나, 몰입, 무엇에 기운이 났나, 글의 해석 | 고양이의 **자리** | 천천히 |
| **상태** | 잔 시간, 잠 만족도, 오늘의 기운, 하루 만족도 | 고양이의 **모습** (부스스함, 기지개 등) | 매일 |

상태는 성향 계산의 보정에도 쓴다(6장).

## 5. 척도

### 5.1 성향 척도 (고정, 10개)

각 척도는 -2에서 +2까지다. 0은 어느 쪽도 아님을 뜻한다.

| ID | 척도 | -2 | +2 |
|---|---|---|---|
| `social` | 기운이 오는 곳 | 혼자 | 함께 |
| `pace` | 속도 | 느긋하게 | 빠르게 |
| `frame` | 틀 | 계획대로 | 그때그때 |
| `object` | 마음이 가는 대상 | 사람 | 사물·생각 |
| `mode` | 방식 | 받아들이기 | 만들어 내기 |
| `span` | 폭 | 하나를 깊게 | 여럿을 넓게 |
| `noise` | 환경 | 고요함 | 북적임 |
| `body` | 쓰는 감각 | 머리 | 몸·손 |
| `novelty` | 새로움 | 익숙한 것 | 처음인 것 |
| `reward` | 즐거움의 자리 | 과정 | 결과·성취 |

후보로 남겨 둔 척도: `care` (나를 채우기 ↔ 남을 돌보기). 지금 하는 활동에서는 신호가 거의 나오지 않아 뺐다. AI의 척도 제안(8.3)으로 다시 들어올 수 있다.

### 5.2 상태 지표

`sleepHours`, `sleepSat`(1~5), `wakeHow`, `energy`(하루 평균 기운), `daySat`(1~5).

### 5.3 누른 답이 척도가 되는 규칙

누른 답은 AI 없이 바로 점수가 된다. 기운 표시가 붙은 답은 **기운이 난 쪽으로 끌리고 빠진 쪽에서 밀린다.**

| 답 | 기본 점수 |
|---|---|
| 길: 북적북적 | `noise` +2 |
| 길: 한적 / 시골길·자연 | `noise` -2 |
| 길: 나만의 길 | `social` -1, `frame` +1 |
| 길: 늘 같은 길 | `novelty` -2 |
| 길: 처음 가 본 길 | `novelty` +2 |
| 가는 동안: 책 | `mode` -1 |
| 가는 동안: 멍 / 생각 정리 | `pace` -1, `social` -1 |
| 일: 혼자 한 일이 많음 / 사람이 많음 | `social` -2 / +2 |
| 누구와: 혼자 / 둘이 / 여럿 | `social` -2 / 0 / +2 |
| 저녁: 운동 | `body` +2 |
| 저녁: 바이브코딩 | `mode` +2, `object` +1 |
| 저녁: 독서 | `mode` -2, `body` -1 |

기운의 적용: 기운 ↑이면 기본 점수를 그대로 더한다. →이면 절반만 더한다. ↓이면 **부호를 뒤집어 절반**을 더한다. 예를 들어 북적한 길에서 기운이 빠졌다면 `noise` -1이 된다. 고양이는 "있었던 곳"이 아니라 "기운이 난 곳"으로 간다.

이 표는 1단계에서 실제 기록을 보며 다듬는다. 규칙은 코드에 표로 두어 고치기 쉽게 한다.

## 6. 고양이의 자리 계산

### 6.1 척도별 값

척도마다 관찰 점수의 가중 평균을 낸다. 가중치는 네 가지를 곱한다.

| 가중치 | 값 |
|---|---|
| 골랐나 | 골랐다 1.0 / 어쩌다 보니 0.5 / 해야 해서 0.25 / 표시 없음 0.7 |
| 시간 | 최근일수록 크다. 90일마다 절반으로 줄어든다 |
| 확신도 | 누른 답 1.0 / AI 해석은 AI가 준 확신도(0~1) |
| 컨디션 | 잠 만족도 1~2인 날의 "기운 ↓" 관찰은 0.5 |

### 6.2 장소

장소마다 척도 조합(원형)을 정해 둔다. 고양이의 척도 값과 가장 닮은 장소가 **지금 자리**가 되고, 두 번째로 닮은 장소 쪽으로 살짝 기운다.

| 장소 | 닮은 고양이 |
|---|---|
| 볕 드는 창가 | 혼자, 느긋, 고요, 받아들이기 |
| 다락 서재 | 혼자, 깊게, 머리, 받아들이기 |
| 작업대 | 만들어 내기, 몸·손, 깊게, 과정 |
| 골목 담장 위 | 혼자, 그때그때, 처음인 것, 넓게 |
| 시장 골목 | 함께, 빠르게, 북적임, 사람 |
| 동네 평상 | 함께, 느긋, 사람, 익숙한 것 |
| 운동장 트랙 | 몸·손, 빠르게, 결과·성취, 계획대로 |
| 뒷산 오솔길 | 몸·손, 혼자, 고요, 과정 |
| 옥상 | 생각, 혼자, 그때그때, 넓게 |
| 부엌 식탁 | 함께, 만들어 내기, 익숙한 것, 몸·손 |

장소 목록과 원형 값은 초안이다. 1단계에서 기록이 쌓이면 함께 조정한다.

### 6.3 자리 잡는 정도

관찰이 적을 때는 자리가 흔들린다. 관찰 수와 1·2위 장소의 차이로 **자리 잡은 정도**를 셋으로 나눈다.

- **돌아다니는 중:** 관찰 20개 미만. 고양이가 여러 장소를 오간다.
- **기웃거리는 중:** 한 장소에 자주 있지만 2위와 차이가 작다.
- **자리 잡음:** 한 장소에 앉아 있다.

고양이를 누르면 **"왜 여기 와 있나"**를 보여 준다. 척도별 값, 그 값을 만든 최근 관찰 몇 개(원문 그대로), 지난달과 달라진 점이다.

## 7. 고양이의 질문

### 7.1 언제

처음 한 번 평소 기상·출근·퇴근·취침 시각과 출근 요일을 받는다. 그 시간대에 앱을 열면 고양이가 말풍선으로 묻는다. 기록된 시각이 쌓이면 시간대를 스스로 맞춘다.

### 7.2 무엇을 (우선순위 순)

1. **빈칸:** 지금 시간대의 일과 중 아직 안 채운 것
2. **이어 묻기:** 오늘 답한 것의 다음 질문. 읽는 중인 책이 있으면 "오늘 머문 문장 있어?"
3. **덜 채워진 척도:** 관찰이 적은 척도 쪽의 질문 (예: "오늘 시간이 가장 빨리 간 순간은?")
4. **확인하기:** 패턴이 보이면 되묻는다 (예: "요즘 운동한 날마다 기운이 났네. 맞아?"). 답은 그 패턴의 확신도를 올리거나 내린다

1~3은 규칙으로 고르고 질문 문장은 미리 써 둔 목록에서 뽑는다. AI가 필요 없다. 4는 통계로 패턴을 찾고, 문장만 3단계부터 AI가 다듬는다.

### 7.3 규칙

- 고양이는 **지금 시간대의 칸만** 묻는다. 한 칸은 누르기 3~4번이다
- 지나간 시간대의 빈칸은 "같이 되짚어 볼까?" 하고 먼저 묻고, 그러자고 할 때만 이어서 묻는다
- 질문 하나는 누르기 1~2번으로 끝난다
- "오늘은 넘어갈래"가 늘 있다. 넘어간 질문은 그날 다시 묻지 않는다
- 며칠 비워도 밀린 질문을 쌓아 두지 않는다. 오늘 것만 묻는다

## 8. AI

### 8.1 하는 일

AI는 **글을 읽을 때만** 쓴다. 누른 답은 5.3의 규칙으로 처리한다.

| 일 | 입력 | 출력 |
|---|---|---|
| 글 해석 | 순간·생각·한 줄·문장에 붙인 내 생각 | 영역, 척도별 점수(-2~+2), 근거 문장, 확신도 |
| 패턴 문장 | 통계로 찾은 패턴 | 고양이가 건넬 확인 질문 한 문장 |
| 척도 제안 | 최근 관찰 묶음 | 기존 척도로 설명되지 않는 반복 주제 (4단계) |

해석 결과의 형식:

```json
{
  "area": "몸 쓰기",
  "scores": [
    { "scale": "social", "value": -2, "confidence": 0.8, "evidence": "혼자 뛸 때 생각이 정리됐다" }
  ]
}
```

근거 문장은 원문에 있는 구절이어야 한다. 원문에 없으면 그 점수는 버린다.

### 8.2 연결과 동의

```
폰(앱) → 중계소(Cloudflare Worker) → AI API
```

- 지금 도서 검색에 쓰는 중계소에 `/interpret` 경로를 더한다. AI 열쇠는 중계소의 Secret에만 둔다.
- 모델은 가벼운 것(Claude Haiku 계열)으로 시작한다. 정확한 모델과 비용은 2단계에서 확인한다.
- 지금 앱은 "본문 기록은 서버로 보내지 않는다"고 약속했다. 그래서 **처음 한 번 동의 화면**을 띄운다. 무엇이 어디로 가는지, 중계소는 글을 저장하지 않는다는 것, 끄는 방법을 적는다. 동의 전에는 누른 답만으로 고양이가 움직인다.
- 책 본문(인용한 문장)은 저작물이므로 보내지 않는다. 문장에 붙인 **내 생각**만 보낸다.
- 오프라인에서 쓴 글은 대기열에 두었다가 연결되면 모아서 보낸다.
- 중계소는 하루 호출 수에 한도를 둔다.

### 8.3 척도 제안

기록이 100개쯤 쌓이면 AI가 "기존 척도로 설명되지 않는 반복 주제"를 제안한다. 사용자가 받아들이면 척도가 추가되고, 지난 글을 새 척도로 다시 해석한다. 고정 척도 10개는 지우지 않는다. 시간에 따른 변화를 비교하려면 기준이 남아 있어야 한다.

## 9. 화면

탭은 넷이다.

| 탭 | 내용 |
|---|---|
| **고양이** (첫 화면) | 지금 자리의 배경 위에 고양이. 말풍선 질문, 순간 남기기 버튼, 고양이를 누르면 "왜 여기 와 있나" |
| **하루** | 오늘의 일과 칸과 순간 목록. 날짜를 넘겨 지난 날 보기 |
| **책장** | 지금의 책장과 책 화면 그대로 (문장, 질문) |
| **생각** | 지금의 생각 화면 그대로 |

- 지금의 "질문" 탭(모든 책의 질문 모아 보기)은 책장 안의 필터로 옮긴다.
- 전체 장소 지도는 고양이 화면에서 펼쳐 본다. 지나온 자리가 발자국으로 남는다.
- 보관함(백업·복원)은 그대로 둔다.
- 종이 질감과 녹색 잉크 톤은 유지한다. 지금의 방 그림은 "다락 서재" 장소의 배경으로 쓴다.

### 10.2 지금 기록의 이전

- IndexedDB 이름 `reading-notebook-v2`는 그대로 쓴다. 이름을 바꾸면 기존 기록이 안 보이게 되기 때문이다.
- 버전 2 → 3 이전은 `normalize()`에서 한다. 책·문장·질문·생각은 그대로 둔다. 여행(`trips`)은 `place`가 붙은 순간으로 옮긴다.
- 이전 직전의 버전 2 상태를 `legacy-v2` 키로 따로 보관한다. 지난번 `legacy-original`과 같은 방식이다.
- 버전 2 백업 파일도 계속 복원할 수 있게 한다.
- 이전 테스트를 먼저 쓰고 구현한다.

## 11. 만드는 순서

| 단계 | 내용 | 끝나면 |
|---|---|---|
| **1. 관찰** | 이름 변경, 버전 3 데이터와 이전, 고양이 첫 화면(자리 고정), 하루 일과, 순간, 규칙 기반 질문 | 매일 기록을 쌓기 시작한다 |
| **2. AI 해석** | 중계소 `/interpret`, 동의 화면, 글 해석과 대기열, 쌓인 글 한꺼번에 해석 | 글에도 척도 점수와 근거가 붙는다 |
| **3. 자리** | 장소 원형 확정, 자리 계산, 고양이 이동과 모습, "왜 여기 와 있나", 확인 질문 | 고양이가 움직인다 |
| **4. 척도 제안** | AI의 새 척도 제안, 지도와 발자국 | 척도가 나에게 맞게 자란다 |

1단계는 AI도 자리 계산도 없이 끝난다. 척도 규칙(5.3)과 장소(6.2)는 1단계에서 쌓인 실제 기록을 보고 확정한다.
