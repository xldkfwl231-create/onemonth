# 독서 기록장 — 디자인 시안 프롬프트 (2차 · 책 중심)

다른 AI 디자인 도구에 넘겨 시안을 받기 위한 프롬프트 모음입니다.

**쓰는 법**: 아래 `[공통 블록]`을 먼저 통째로 붙이고, 그 뒤에 원하는 화면 프롬프트 하나를 이어 붙입니다.

> 1차 프롬프트(`design-prompts.md`)는 운동·여행이 있던 시절의 밝은 회색 종이 톤입니다.
> 지금은 방향이 달라졌으니 이 문서를 쓰세요.

---

## [공통 블록] — 매번 앞에 복사

```
이것은 "기록장"이라는 개인 독서 기록 앱의 화면 디자인이다.
한 사람이 매일 혼자 쓰는 도구다. 소셜 기능도, 공유 기능도, 광고도,
상점이나 유료 아이템도 없다. 앞으로도 넣지 않는다.

■ 무엇을 하는 앱인가
읽은 책마다 두 가지를 쌓는다.
  - 문장: 읽다가 걸린 문장을 옮겨 적는다 (저자가 한 말)
  - 질문: 읽다가 생긴 물음. 나중에 답을 달면 짝이 된다 (내 물음)
그리고 책과 상관없는 생각을 아무 때나 던져두는 칸이 따로 있다.

■ 규모 (아주 중요 — 화려한 대시보드를 그리지 말 것)
실제 사용자의 데이터는 이 정도다.
  책 2권 / 문장 25개 / 질문 3개 / 생각 11개
많은 데이터를 전제로 한 통계, 그래프, 차트, 순위, 배지, 연속 기록,
성취도 같은 것은 넣지 않는다. 숫자를 과시하는 UI는 이 앱에 맞지 않는다.

■ 톤
"오래 쓰는 문구류"에 가깝다. 앱스토어 감성이 아니다.
따뜻한 크림 종이 위에 짙은 녹색 잉크. 조용하고, 글이 주인공이다.
귀여운 마스코트나 캐릭터는 쓰지 않는다.

■ 디자인 토큰 (반드시 이 값만 사용)
배경            #F6F2E8
카드·표면       #FCFAF3
한 톤 어두운 종이 #EFE9DA
본문 잉크        #262A22
보조 글씨        #5C6154
흐린 글씨        #96988A
더 흐린 글씨      #C6C2B2
선              #E2DCCC
연한 구분선      #E9E3D4

강조(초록, 문장) #2F4A38   연한 배경 #E6EDE1   테두리 #CBDAC4
보조(파랑, 질문) #35507A   연한 배경 #DCE4EF   테두리 #C2CFE2

글꼴
  제목·문장 본문 : Gowun Batang (명조), 400 / 700
  UI·설명 본문   : IBM Plex Sans KR, 300 / 400 / 500
  숫자·날짜·단위 : IBM Plex Mono, 400 / 500 / 600

모서리 반경 3~4px (동그란 알약형은 999px)
그림자는 책 표지에만 아주 옅게. 나머지는 1px 테두리로만 구분한다.
아이콘은 선 아이콘(stroke 1.6~1.9)만. 이모지·컬러 아이콘·면 아이콘 금지.

■ 레이아웃
모바일 전용. 아트보드는 375x812로 그린다.
누르는 것은 무엇이든 최소 44px 높이를 확보한다.
다크모드는 필요 없다(단 하나, "사진에서 범위 고르기" 같은 화면만 예외).
아이폰 상태바(시각·배터리)나 가상 키보드를 그려 넣지 말 것.
실제 폰에서 그 자리에 진짜가 올라오므로 겹쳐 보인다.

■ 글은 실제 문장으로
lorem ipsum이나 "샘플 텍스트"를 쓰지 않는다.
아래는 이 사용자가 실제로 기록한 것들이다. 이 결과 그대로 쓰거나,
같은 결의 한국어 문장을 쓴다.

  문장 (책 「독서의 기술」에서)
    "나 자신이 배제된 해결책은 효과가 없다.
     해결을 타인에게 맞추지 말고 나 자신에 맞추자."
    "집에서 책을 읽는것보다 독서를 위해 행동이 동반되면
     신경세포(뉴런)이 10배 강하게 활동한다.
     그러니 집보다는 도서관, 카페 등 나가서 독서"
    "다크심리학
     = 착함은 악함앞에서 무릎 꿇는게 아니라 악함을 이기는것"

  질문
    "YouTube 영상보다 책이 나에게 이점이 되는 이유는?"  (답 없음, 39일째)
    "핸드폰이 안 좋은 이유가 행동이 동반되지 않아서라면,
     전자책은 어떤가?"
      답 → "책장을 넘기고 손으로 만지고 책의 향기를 느끼는 활동이 없어,
            전자책도 행동을 동반하지만 책 만큼은 아님."

  생각
    "땀의 양이 실력을 키우는게 아니라 불편함의 양이 실력을 키운다"
    "쉬는 날을 미리 정하지 말 것"

  책 제목 : 독서의 기술 / 어떻게 살아낼 것인가
```

## 1. 방 — 첫 화면

[공통 블록]

```
앱을 열면 처음 보이는 "방" 화면을 디자인해줘.

이 화면의 성격: 탭 목록 대신 방 그림 하나가 길잡이다.
방 안의 물건을 눌러서 들어간다.
  - 벽에 걸린 메모판을 누르면 → 생각
  - 책장을 누르면 → 책

담아야 할 것
  - 위: 오늘 날짜(모노, 흐리게) + "기록장"(명조 700)
  - 가운데: 방 그림. 선으로 그린 그림이며 색은 위 토큰만 쓴다.
      메모판(벽), 책장, 책상과 스탠드 정도면 충분하다.
      누를 수 있는 두 물건(메모판·책장) 아래에는
      짙은 녹색 알약 라벨로 개수를 단다. 예: "생각 11" / "책 2"
      그 아래 한 줄 안내: "메모판을 누르면 생각" / "책장을 누르면 책"
  - 아래: 지금 읽는 책 한 줄 (작은 표지 + "읽는 중" + 제목 + [문장] 버튼)
  - 맨 아래: 탭바 3칸 (방 / 책장 / 생각)

가장 중요한 것
  책장은 장식이 아니라 기록과 연결된다.
  읽은 책이 실제로 한 권씩 꽂히고, 빈 칸은 옅은 점선으로 남는다.
  지금은 2권뿐이라 맨 위 칸에만 두 권이 서 있고 나머지는 비어 있다.
  이 "아직 비어 있음"이 초라해 보이지 않고 여백으로 읽히게 해줘.

하지 말 것
  캐릭터·마스코트·고양이. 상점·코인·꾸미기 아이템.
  방을 꽉 채우려 하지 말 것. 물건 서너 개면 된다.

아트보드 2개로
  (1) 위와 같이 책 2권이 꽂힌 상태
  (2) 책이 12권쯤 쌓여 책장이 두세 칸 찬 상태
```

## 2. 책 — 한 권의 첫 화면

[공통 블록]

```
책 한 권을 열었을 때의 화면을 디자인해줘.

담아야 할 것
  - 위: 뒤로가기 / 가운데 작은 모노 라벨 / 더보기(점 세 개)
  - 표지 가로 캐로셀: 가운데 책이 크게(약 124x178), 양옆 책은
    작고 흐리게 반쯤 보인다. 좌우로 넘겨 책을 바꾼다.
  - 제목(명조 700, 가운데 정렬) + 그 아래 한 줄 (예: "8월 1일부터 읽는 중")
  - 큰 원형 버튼 2개를 나란히. 지름 90px 안팎.
      문장 (연한 초록 원 + 따옴표 아이콘) — 원 아래 "문장" / 개수 "23"
      질문 (연한 파랑 원 + 물음표 아이콘) — 원 아래 "질문" / "5 · 답 2"
  - 그 아래 "최근": 문장·질문 섞어서 2~3개.
      각 항목은 [유형 알약 라벨] + [날짜] + [본문]
  - 맨 아래: 탭바

하지 말 것
  진행률 바, 몇 쪽 읽었는지, 읽은 날짜 달력, 별점.
  전부 사용자가 매번 손으로 입력해야 하는 값이라 뺐다.

아트보드 2개로
  (1) 기록이 쌓인 상태 (위 그대로)
  (2) 방금 추가해서 문장 0 · 질문 0인 상태.
      원 두 개가 비어 있을 때 초라하지 않게 보이는 방법을 제안해줘.
```

## 3. 문장 — 날짜로 접고 펴기

[공통 블록]

```
한 책의 "문장" 목록 화면을 디자인해줘.

이 화면의 성격: 문장이 23개 쌓여 있다. 앞으로 200개가 되어도
훑어보기 지치지 않아야 한다. 그래서 날짜로 묶고 접는다.

담아야 할 것
  - 위: 뒤로가기 / 책 제목(작게) / 검색
  - 탭 줄: [문장 23] [질문 5] — 고른 쪽만 명조 700 + 아래 2px 밑줄.
    같은 줄 오른쪽 끝에 "모두 접기"
  - 날짜 줄이 곧 버튼이다. 높이 46px.
      [꺾쇠 아이콘] [8/15] [6]
      펼쳐진 날은 꺾쇠가 아래(∨)·글자가 진하고, 접힌 날은 오른쪽(>)·흐리다.
  - 펼쳐진 날 아래에 그 날 문장들. 날짜 줄보다 살짝 들여쓴다.
      각 문장은 [쪽수(선택, 모노 초록, 예 p.142)] + [본문(명조 15.5px, 줄간 1.8)]
      + [한 줄 메모(선택, 작고 흐리게, 들여쓰기)]
      쪽수와 메모는 없을 수도 있다. 없으면 그 줄 자체가 없다.
  - 맨 아래: [+ 문장 넣기] 꽉 찬 짙은 녹색 버튼

가장 중요한 것
  펼친 날 하나 + 접힌 날 대여섯 개가 한 화면에 같이 보여야 한다.
  접힌 줄이 단조로운 목록으로 보이지 않게 리듬을 잡아줘.
  줄바꿈이 들어간 문장(위 "다크심리학" 예시)이 원문 그대로
  줄이 살아서 나와야 한다. 한 줄로 뭉개지면 안 된다.

아트보드 3개로
  (1) 맨 위 날짜만 펼친 상태
  (2) 전부 접힌 상태 — 날짜 줄만 10개쯤
  (3) 아직 문장이 하나도 없는 상태
```

## 4. 문장 넣기

[공통 블록]

```
문장을 새로 넣는 화면을 디자인해줘. 아래에서 올라오는 시트다.

담아야 할 것
  - 맨 위 가운데 짧은 손잡이 막대
  - "문장 넣기"(모노 소문자 라벨) + 책 제목(명조 700) / 오른쪽 "취소"
  - 큰 입력칸: 걸린 문장. 명조로 쓰고 여러 줄이 들어간다.
    비어 있지 않고 실제 문장이 들어간 상태로 그려줘.
  - 그 아래 두 칸이 나란히
      왼쪽 좁게: "쪽 · 선택"   (모노, 비어 있으면 흐린 "p.")
      오른쪽 넓게: "한 줄 메모 · 선택"
  - [기록] 꽉 찬 짙은 녹색 버튼
  - 맨 아래 가운데 작은 안내: "쪽과 메모는 비워둬도 됩니다"

가장 중요한 것
  "선택"이라는 것이 눈에 보여야 한다.
  쪽과 메모를 비워두는 게 게으른 게 아니라 정상이라고 느껴지게.

가상 키보드는 그리지 말 것.
```

## 5. 질문 — 물음과 답

[공통 블록]

```
한 책의 "질문" 목록 화면을 디자인해줘. 이 앱에서 가장 중요한 화면이다.

이 화면의 성격: 읽다가 생긴 물음을 적어둔다. 바로 답할 수 있는 것은
사실 질문이 아니다. 그래서 "아직 답이 없는 질문"이 위에 오고,
답을 달면 아래로 내려간다.
물은 날과 답한 날 사이의 간격이 함께 남는다 — 이게 핵심 값이다.

담아야 할 것
  - 위: 뒤로가기 / 책 제목 / 검색
  - 탭 줄: [문장 23] [질문 5] — 질문이 선택됨
  - "아직 답이 없는 질문 · 2" 라벨
      각 질문은 카드(흰 표면 + 1px 테두리):
        [Q 표시(모노, 초록)] + 질문 본문(명조)
        아래: "8/4에 물음 · 39일째"(모노, 흐리게) + [답 쓰기] 알약 버튼
  - "답을 단 질문 · 1" 라벨 (선으로 구분)
      답이 달린 것은 카드 없이 평평하게, 조금 흐리게:
        [Q] 질문(흐린 글씨) → [A] 답(본문색, 산세리프)
        답 아래: "8/15에 물어 같은 날 답함 · 바로 나옴"
  - 맨 아래: [+ 질문 넣기]

가장 중요한 것
  "39일째 답이 없다"가 부끄러움이 아니라 기다림으로 읽혀야 한다.
  경고색(빨강)이나 느낌표를 쓰지 말 것.
  답이 달린 질문과 안 달린 질문의 무게 차이를 색이 아니라
  형태(카드 유무)와 농도로 만들어줘.

아트보드 3개로
  (1) 위와 같은 섞인 상태
  (2) 전부 답이 없는 상태
  (3) 답을 쓰는 중인 화면
```

## 6. 책장

[공통 블록]

```
책 목록 화면을 디자인해줘.

담아야 할 것
  - "책장"(명조 700) + 오른쪽 [+ 책 추가] 버튼
  - 알약 필터 2개: [읽는 중 2] [다 읽음 0]
  - 표지 2열 격자. 표지가 화면을 끄는 주인공이다.
    표지 아래: 제목 한 줄 + [문장 23] · [질문 3] (모노, 작게)
  - 맨 아래: 탭바

표지에 대하여
  책 표지 이미지는 사용자가 직접 사진을 고르거나, 안 고르면
  제목 글자로 만든 표지가 자동으로 생긴다. 인터넷 검색은 쓰지 않는다.
  두 경우가 한 화면에 섞여 있어도 어색하지 않게 만들어줘.
  글자 표지는 색 바탕 + 명조 제목 + 아래쪽 작은 모노 한 줄 정도.

아트보드 3개로
  (1) 2권 (지금 상태)
  (2) 14권쯤 쌓인 상태 — 사진 표지와 글자 표지가 섞여 있게
  (3) 한 권도 없는 상태
```

## 7. 책 추가

[공통 블록]

```
책을 새로 넣는 화면을 디자인해줘.

인터넷 검색은 쓰지 않는다. 사용자가 직접 적는다.

담아야 할 것
  - 제목 입력 (필수)
  - 저자 입력 (선택)
  - 표지 정하기:
      [사진 고르기] — 폰 앨범에서 표지를 찍은 사진을 고른다
      또는 글자 표지 — 바탕색을 네댓 개 중에 고른다.
        고른 색으로 표지가 바로 미리 보인다.
  - [책장에 넣기] 버튼

가장 중요한 것
  표지 없이 넘어가도 전혀 아쉽지 않아야 한다.
  글자 표지 미리보기가 실제 결과와 똑같이 보이게 해줘.
```

## 8. 생각

```
책과 상관없는 "생각" 화면을 디자인해줘.

이 화면의 성격: 분류하지 않는다. 정리하지도 않는다.
새벽에 걷다가, 자기 직전에, 아무 때나 떠오른 것을 그대로 던져둔다.
나중에 쓸모없어 보여도 지우지 않는다.
따라서 폴더, 태그, 검색, 즐겨찾기, 고정 같은 "관리" UI가 있으면 안 된다.

담아야 할 것
  - "생각"(명조 700)
  - 한 줄 입력칸 (placeholder는 "아무거나") + 오른쪽 화살표 버튼
  - 날짜로 묶인 목록. 최근이 위.
      날짜 줄은 [모노 날짜] + [가는 가로선]
      그 아래 그 날의 생각들. 날짜는 항목마다 반복하지 않는다.
  - 맨 아래: 탭바

가장 중요한 것
  한 줄짜리와 대여섯 줄짜리가 섞여 있다. 줄바꿈이 들어간 것도 있다.
  길이가 들쭉날쭉해도 읽는 리듬이 무너지지 않게 해줘.
  100개가 되어도 훑어보기 지치지 않아야 한다.
  날짜 접기를 넣는 게 나을지도 같이 제안해줘.

아트보드 3개로
  (1) 11개쯤 쌓인 상태 (짧은 것과 긴 것이 섞이게)
  (2) 비어 있는 상태 ("비어 있습니다.")
  (3) 항목을 눌러 그 자리에서 고치는 상태 (저장/취소)
```
