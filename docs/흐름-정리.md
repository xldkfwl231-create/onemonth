# 기록 → 이야기 흐름 정리 (2026-10-10, 빌드 1012c 기준)

테스트 자료(가상 책 1권, 문장 2, 질문 2, 생각 3, 답 1, 이야기 2)를 넣은 미리보기에서 책장 · 책 · 남은 질문 · 생각 · 나 · 이야기 화면을 차례로 열어 보고 코드와 맞춰 본 결과입니다.

## 1. 지금 화면 지도

```
[슬라임]  [책장]                    [생각]               [나]
   │        ├ 책 ─┬ 문장 카드         └ 생각 카드          ├ 이야기 목록 ── 이야기
   │        │     └ 질문 카드            (이야기하기)      ├ 슬라임에게 한 답
   │        └ 남은 질문 (모든 책)                          ├ 아직 품은 질문 → 남은 질문
   └ ? 슬라임의 질문 → 답 (나 아래에 모임)                 ├ 책 → 책장 / 생각 → 생각
                                                           └ 설정들
  문장·질문·생각·책 ──"이야기하기"──▶ 이야기 ──"생각으로 남기기"──▶ 생각 탭
```

## 2. 뒤죽박죽으로 느껴지는 이유 (7가지)

| # | 어디서 | 무엇이 꼬였나 |
|---|---|---|
| 1 | 이야기 | 앱의 중심 활동인데 탭이 없습니다. **나 → 기록 모아보기 → 이야기**로 두 번 들어가야 하고, 이야기에서 나가면 문장·질문이 아니라 **나**로 돌아갑니다. |
| 2 | 문장·질문·생각 카드 | 이야기를 나눴어도 카드에 아무 표시가 없습니다. 이야기가 있는지, 몇 마디인지 알 수 없습니다. |
| 3 | 이야기의 결과 | "생각으로 남기기"를 누르면 **책 질문에 대한 이야기도 생각 탭으로** 갑니다. 생각 탭은 "책과 상관없이 떠오른 것"이라 정의와 어긋나고, 어느 책·어느 질문에서 나온 말인지 사라집니다. 질문의 답은 그대로입니다. |
| 4 | 말(이름) | **생각**이 생각 탭, 문장에 다는 "내 생각 · 선택", 이야기에서 남긴 말까지 세 가지를 뜻합니다. **질문**도 책 질문, 슬라임의 질문(물음표 단추), 남은 질문 화면으로 세 가지, **답**도 질문에 단 답과 슬라임에게 한 답으로 두 가지입니다. |
| 5 | 흩어진 자리 | 남은 질문은 책장 탭에 속하는데 나에서도 들어갑니다. 슬라임에게 한 답은 나 안에만 있습니다. 같은 무게의 기록이 세 탭에 흩어져 있습니다. |
| 6 | 책 화면 | 문장 · 질문 큰 카드에 **→ 화살표**가 있어 다른 화면으로 가는 것처럼 보이지만, 실제로는 아래 목록만 바꾸는 탭입니다. |
| 7 | 슬라임에게 한 답 | 이야기하기 단추가 없습니다. 슬라임이 물어서 생긴 기록인데, 그 질문을 이어서 이야기할 수 없습니다. |

## 3. 제안: 한 바퀴로 도는 흐름

> **정한 것 (2026-10-10):** 갈래는 둘입니다.
> - **책 갈래:** 문장 → 질문 → 이야기. 책 이야기의 결과는 책 안(문장 아래 덧붙임, 문장에서 생긴 질문, 질문의 지금의 답)에 남습니다.
> - **생각 갈래:** 생각 → 이야기. 생각은 말 그대로 생각이라, 생각 이야기의 결과만 생각 아래에 덧붙습니다.
> - 1단계(3-1, 3-2)는 빌드 1012d에 들어갔습니다. 문장 카드에 **질문 만들기**도 생겼습니다.
> - 2단계(3-3 이야기 탭)는 빌드 1012e에 들어갔습니다. 탭은 슬라임 · 책장 · 생각 · 이야기 · 나. 이야기 탭은 갈래 단추(전체 · 책 · 생각 · 슬라임의 물음)로 나뉘고, 슬라임의 물음에 한 답도 이야기하기 → 답 아래 덧붙이기가 됩니다. 나에는 슬라임 카드 · 오늘의 말 · 설정만 남았습니다.
> - 3단계(3-4 이름 정리, 3-5 책 화면)는 빌드 1012f에 들어갔습니다. 남은 질문은 '모든 책의 질문'(책장의 '답을 기다리는 질문 N ›'로 들어감)으로 이름을 바꿨습니다.

> **남긴다 → 이야기한다 → 처음 자리로 돌아가 남긴다**

```
문장 ─┐                                ┌─▶ 문장의 메모에 더하기
질문 ─┤                                ├─▶ 질문의 '지금의 답'으로 (그땐 → 지금은)
생각 ─┼─▶ 이야기하기 ─▶ 이야기 ─▶ 남기기 ┼─▶ 이 생각에 덧붙이기
답   ─┤                                ├─▶ 이 답에 덧붙이기
새 이야기 ┘                            └─▶ (새 이야기만) 생각으로
```

### 3-1. 이야기의 결과는 처음 자리로 (#3, #7)
- "생각으로 남기기" 대신, 무엇으로 시작했는지에 따라 단추가 바뀝니다.
  - 질문으로 시작 → **"지금의 답으로 남기기"**. 예전 답은 지우지 않고 **"그땐"**으로 남기고, 새 답은 **"지금은"**으로 둡니다. 앱이 원래 하려던 "그땐 그랬지만 지금은" 흐름이 기록 안에서 바로 보입니다.
  - 문장으로 시작 → **"이 문장 메모에 더하기"**
  - 생각·답으로 시작 → **"이 생각에 덧붙이기"** (원래 생각 아래에 날짜와 함께 이어 붙임)
  - 새 이야기(주제 없음) → 지금처럼 **생각으로 남기기**
- 남긴 말은 지금처럼 슬라임의 방울이 됩니다.

### 3-2. 카드에 이야기 표시 (#2)
- 이야기를 나눈 카드는 단추가 **"이야기 이어가기 · 6마디"**로 바뀝니다.
- 이야기 화면의 "←" 단추는 **처음 그 카드가 있던 화면**으로 돌아갑니다.

### 3-3. 탭을 다섯으로 (#1, #5)
| 탭 | 들어 있는 것 |
|---|---|
| 슬라임 | 지금처럼 |
| 책장 | 책 → 문장 · 질문, 남은 질문 |
| 생각 | 혼자 떠오른 것 (지금처럼) |
| **이야기** (새로 생김) | 내가 꺼낸 이야기 + **슬라임이 물어서 한 답** = 슬라임과 주고받은 모든 것 |
| 나 | 슬라임 카드, 오늘의 말, 설정 (기록 목록은 뺌) |

- "슬라임에게 한 답"은 슬라임이 묻고 내가 답한 짧은 대화입니다. 그래서 이야기 탭에 두면 **생각(혼자) / 이야기(슬라임과 함께)**로 깔끔하게 갈립니다. 생각 탭과는 지금처럼 따로입니다.

### 3-4. 이름 정리 (#4)
| 지금 | 바꿀 이름 | 이유 |
|---|---|---|
| 문장의 "내 생각 · 선택" | **메모** | 생각 탭과 겹침 |
| 슬라임의 질문 (물음표) | **슬라임의 물음** | 책 질문과 구분 |
| 남은 질문 | **답을 기다리는 질문** | 무엇이 남았는지 분명하게 |
| 질문에 단 답 | **지금의 답** (예전 답은 "그땐") | 슬라임에게 한 답과 구분 |

### 3-5. 책 화면 (#6)
- 문장 · 질문 큰 카드를 **나란한 탭 단추**로 바꾸고 → 화살표를 뺍니다.
- 위쪽 단추 셋(책 정보 수정 / 이야기하기 / 다 읽었어요)은 **이야기하기**만 크게, 나머지 둘은 작게.

## 4. 바꾸는 순서 (제안)

1. **결과를 처음 자리로** (3-1) + **카드에 이야기 표시** (3-2). 흐름이 가장 크게 좋아집니다. 질문 답 기록에 "그땐" 목록을 추가해야 하므로 저장 형식에 칸이 하나 늘어납니다. 기존 기록은 그대로 읽힙니다.
2. **이야기 탭** (3-3).
3. **이름 정리 + 책 화면** (3-4, 3-5). 글자와 모양만 바뀝니다.

## 부록: PC 모드 (빌드 1012c에서 추가)

- 이야기 화면 오른쪽 위 **PC** 단추, 또는 **나 → PC 모드**.
- 켜면 아래 탭을 숨기고 화면 높이를 다 씁니다. 글씨가 조금 커지고, Enter로 보내고 Shift+Enter로 줄을 바꿉니다.
- 좁은 화면에서는 **문서 모양 단추**를 눌러 배경(책·문장·메모)을 위에 펼칩니다. 배경의 메모를 누르면 입력칸에 인용되고 창이 닫힙니다.
- 예전에 "Enter로 보내기"를 켜 두었다면 PC 모드가 켜진 상태로 시작합니다.

## 부록: PC 서재 (빌드 1012j)

- 노트북 크기(가로 1100px 이상)에서 세 칸: **왼쪽 기록**(이 책의 문장·질문, 최근 생각, 다른 이야기) · **가운데 이야기**(말풍선 대신 공책 대화록) · **오른쪽 남길 말**(남길 자리 고르기, 내 말 가져오기, Ctrl+S로 남기기, 이 기록에 남긴 것).
- 760~1099px은 가운데 + 오른쪽 두 칸, 그보다 좁으면 지금처럼 한 칸.
- **이야기는 내가 먼저:** 슬라임의 첫 질문을 없애고, 맨 위에 무엇에 대한 이야기인지 주제 카드를 둡니다.
- 따로 뺀 기능: **기록 지도**(빌드 1012k). 첫 화면에서 슬라임을 꾹 누르면 부풀다가 터지고, 그 안의 기록이 주제어 · 책으로 이어진 지도로 펼쳐집니다. 오른쪽 위 지도 단추로도 열립니다.
  - 점: 문장(노랑) · 질문(보라) · 생각(주황) · 답(파랑), 큰 점: 주제어(민트) · 책(갈색). 이야기한 기록은 초록 테두리.
  - 점을 누르면 그 기록 카드(이야기하기 · 기록 보기 · 이어진 것). 끌어서 옮기기, 두 손가락·휠로 확대.
