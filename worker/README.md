# 도서 검색 중계소 — 설치 순서

책 제목으로 표지·저자·출판사를 찾아오기 위한 작은 중계소입니다.
카카오 열쇠를 공개된 `index.html`에 넣을 수 없어서 한 단계를 둡니다.

```
폰(기록장)  →  중계소(열쇠 보관)  →  카카오
```

기록(문장·질문·생각)은 여기를 지나가지 않습니다. **책 찾을 때 제목만** 나갑니다.

---

## 1. 카카오 열쇠 받기 · 5분

1. <https://developers.kakao.com> 접속 → 카카오 계정으로 로그인
2. 상단 **내 애플리케이션** → **애플리케이션 추가하기**
   - 앱 이름: `기록장`
   - 회사명: 아무거나 (본인 이름도 괜찮습니다)
3. 만들어진 앱을 누르면 **앱 키** 목록이 나옵니다
4. 그중 **REST API 키**를 복사해 둡니다

> 카카오 로그인이나 결제 같은 건 켜지 않아도 됩니다. 검색만 씁니다.

## 2. 중계소 만들기 · 10분

1. <https://dash.cloudflare.com> 가입 (무료)
2. 왼쪽 메뉴 **Workers & Pages** → **Create** → **Start with Hello World!**
   - 이름: `book-search` (주소가 `book-search.<계정>.workers.dev` 가 됩니다)
3. 만들어지면 **Edit code** 를 눌러 편집기를 엽니다
4. 안에 있던 예시 코드를 **전부 지우고**, 이 폴더의 `book-search.js` 내용을 붙여넣습니다
5. **Deploy** 를 누릅니다

## 3. 열쇠 넣기 · 2분

**코드에 열쇠를 적지 마세요.** 따로 보관합니다.

1. 그 Worker 화면에서 **Settings** → **Variables and Secrets**
2. **Add** → 종류는 **Secret**
   - 이름: `KAKAO_KEY`
   - 값: 1번에서 복사한 REST API 키
3. **Deploy** 로 반영

## 4. 잘 되는지 확인

브라우저 주소창에 이렇게 쳐 봅니다.

```
https://book-search.<계정이름>.workers.dev/?q=독서의 기술
```

책 목록이 JSON으로 나오면 성공입니다. 이 주소를 알려주시면 앱에 연결하겠습니다.

---

## 알아둘 점

- **열쇠는 저에게 주지 마세요.** 3번처럼 Cloudflare에 직접 넣으시면 됩니다. 저는 완성된 주소만 알면 됩니다.
- 같은 검색어는 하루 동안 중계소가 기억해 두고 씁니다.
- 앱 주소가 바뀌면 `book-search.js` 위쪽 `ALLOWED` 목록을 고쳐야 합니다.
- 표지 이미지는 카카오 서버에서 불러옵니다. 책을 책장에 넣을 때 한 번 받아 폰에 저장해두면, 그 뒤로는 밖으로 나가지 않습니다.
- 검색에 안 나오는 책(절판본·독립출판물)을 위해 **제목 직접 입력**과 **사진 고르기**는 그대로 남겨둡니다.

# 슬라임이 기록 읽기 (AI) — 추가 설치

같은 중계소에 AI 경로(`/ai/tags`)를 더합니다. 새 Worker를 만들 필요는 없습니다.

```
폰(앱)  →  중계소(AI 열쇠 보관)  →  Anthropic Claude (Haiku 5.5)
```

보내는 것: 생각, 슬라임에게 한 답, 책 문장에 단 **내 생각**. 책에서 옮겨 적은 문장은 보내지 않습니다.
중계소는 글을 저장하지 않고, 받은 주제어는 폰에만 남습니다. 앱 보관함에서 **켜기 전까지는 아무것도 보내지 않습니다.**

## 1. 코드 바꾸기 · 2분

1. <https://dash.cloudflare.com> → **Workers & Pages** → `book-search`
2. **Edit code** → 안의 코드를 **전부 지우고** 이 폴더의 `book-search.js` 를 통째로 붙여넣기
3. **Deploy**

책 검색은 그대로 동작합니다.

## 2. AI 열쇠 넣기 · 2분

1. 그 Worker 화면 → **Settings** → **Variables and Secrets** → **Add**
2. 종류 **Secret**, 이름 `ANTHROPIC_KEY`, 값은 Anthropic 콘솔에서 만든 API 키
3. **Deploy**

## 3. 확인

```
https://book-search.<계정이름>.workers.dev/ai/health
```

`{"ok":true,"key":true,...}` 가 나오면 됩니다. `"key":false` 면 2번의 이름이 `ANTHROPIC_KEY` 인지 확인하세요. 열쇠 값은 이 주소에 나오지 않습니다.

## 4. 앱에서 켜기

앱 → 책장이나 생각 탭 위의 **보관함** → **슬라임이 기록 읽기** → **켜기**.
"N개 중 N개를 읽었습니다"가 나오면 끝입니다. 생각 탭에 `#주제어`가 붙고, 슬라임 안의 방울이 주제별로 모이고, 슬라임 색이 요즘 많은 주제 쪽으로 물듭니다.

# 슬라임의 하루 말 (AI 2단계) — 4단계에서 없앰

`/ai/reflect` 가 추가됐습니다. 열쇠(`ANTHROPIC_KEY`)는 이미 들어 있으니 **코드만** 바꾸면 됩니다.

1. Cloudflare → `book-search` → **Edit code** → 전부 지우고 이 폴더의 `book-search.js` 붙여넣기 → **Deploy**
2. 앱을 열면 하루에 한 번, 슬라임이 최근 기록(최대 60개)을 읽고 '그땐 / 지금은 / 그사이' 말 몇 줄과 오늘의 질문을 만들어 둡니다.

비용: 하루 한 번, 입력 1~2만 토큰 정도 → 하루 0.003달러 안팎.

# 슬라임과 이야기 (AI 3단계) — 코드만 다시 붙여넣기

`/ai/chat` 이 추가됐습니다. 이번에도 **코드만** 바꾸면 됩니다 (Edit code → 전부 지우고 붙여넣기 → Deploy).

보내는 것: 대화 내용(최근 30마디), 책 이야기라면 책 제목·저자와 그 책에 단 내 메모·질문·답. 책에서 옮겨 적은 문장은 보내지 않습니다.
비용: 한 번 주고받을 때 입력 수백~수천 토큰 → 0.001달러 안쪽.

---

# 책 정리 · 슬라임의 기억 (AI 4단계) — 코드만 다시 붙여넣기

`/ai/summary` 가 추가되고, `/ai/chat` 이 기억(`memory`)을 받습니다. `/ai/reflect`(하루 말)는 없앴습니다. 이번에도 **코드만** 바꾸면 됩니다 (Edit code → 전부 지우고 붙여넣기 → Deploy).

- 책 정리: 책 화면의 **이 책 정리**. 보내는 것은 그 책의 메모 · 덧붙인 말 · 질문 · 답 · 이야기에서 내가 한 말뿐이고, 책에서 옮겨 적은 문장은 보내지 않습니다(문장은 id로만 가리킴). 한 번에 0.001~0.002달러.
- 기억: 이야기할 때마다 이 앱에 남긴 기록 가운데 지금 이야기와 주제어가 겹치는 것, 최근 것을 합쳐 최대 55개를 함께 보냅니다(책 문장 제외). 한 번 주고받을 때 입력 수천~1만 토큰 → 1~2원 안팎.

---

# 슬라임의 대화 다듬기 (AI 5단계) — 코드만 다시 붙여넣기

`/ai/chat` 의 대화 규칙을 고치고, 답과 함께 **이어서 꺼낼 말(`next`)** 을 2~3개 돌려줍니다. 이번에도 **코드만** 바꾸면 됩니다 (Edit code → 전부 지우고 붙여넣기 → Deploy).

- 빈 맞장구 대신 답마다 하나를 보탭니다: 반대쪽 생각 · 숨은 전제 · 구체적인 예 · 그땐과 지금의 어긋남 · 책의 관점.
- 슬라임은 여전히 되묻지 않습니다. 대신 앱이 답 아래에 이어서 꺼낼 말을 단추로 보여 주고, 누르면 입력칸에 들어갑니다.
- 다시 붙여넣기 전까지는 예전처럼 답만 오고 단추는 나오지 않습니다(앱은 그대로 동작).
- 비용: 답이 JSON 형식이 되고 단추 말이 조금 붙어 출력이 수십 토큰 늘어납니다. 거의 그대로입니다.

# 문장 제목 (AI 6단계) — 코드만 다시 붙여넣기

`/ai/titles` 가 추가됐습니다. 이번에도 **코드만** 바꾸면 됩니다 (Edit code → 전부 지우고 붙여넣기 → Deploy).

- PC 모드 이야기 화면의 왼쪽 목록에서, 책에서 옮긴 문장마다 6~16글자 제목을 붙여 보여 줍니다. 문장을 고치면 다시 붙입니다.
- 보내는 것: 그 책 제목과 문장(한 번에 30개까지). 제목을 만드는 데만 쓰고 중계소에 남기지 않습니다. 원래는 책 문장을 보내지 않았는데, 문장 이야기에서는 이미 그 문장을 보내고 있어 같은 수준으로 맞췄습니다.
- 다시 붙여넣기 전까지는 문장 앞부분이 제목 대신 나옵니다.
- 비용: 문장마다 한 번만, 30개에 입력 1~2천 토큰 → 1원 안쪽.

# 먹이기 한마디 · 기록 요약 (AI 7단계) — 코드만 다시 붙여넣기

`/ai/tags` 가 주제어와 함께 **기록마다 짧은 요약(`gist`)** 을, 방금 먹인 생각이 있으면 **슬라임의 한마디(`bite`)** 를 돌려줍니다. 이번에도 **코드만** 바꾸면 됩니다 (Edit code → 전부 지우고 붙여넣기 → Deploy).

- 먹이기: 생각을 먹이면 슬라임이 "냠. 꼭꼭 씹어 볼게…" 한 뒤, 그 생각을 보고 본 대로 한 줄을 말합니다(칭찬·조언 없이).
- 건드리기: 슬라임이 꺼내는 말은 이제 원문 대신 "10월 3일 · 요약 한 줄"이고, 최근 기록부터 하나씩 과거로 갑니다. 말풍선을 누르면 그 기록으로 갑니다.
- 요약이 없는 예전 기록은 한 번씩 다시 읽어 요약을 붙입니다(25개씩, 앱을 열거나 기록할 때마다).
- 다시 붙여넣기 전까지는 요약 대신 앞부분이, 한마디 대신 "#주제어 맛이 나"가 나옵니다.
- 비용: 기록마다 요약 몇 토큰이 늘고, 예전 기록을 한 번 다시 읽는 비용(기록 100개에 몇 원 수준)이 듭니다.

---

# 짧은 답 · 단추 없앰 (AI 8단계) — 코드만 다시 붙여넣기

`/ai/chat` 답을 2~3문장(150자 안쪽)으로 줄이고, 기억은 날짜 하나와 짧은 인용만 쓰게 했습니다. 7단계에서 더한 "이어서 꺼낼 말(`next`)"은 없앴습니다(앱도 더는 단추를 그리지 않음). **코드만** 바꾸면 됩니다.

# 이어 주기 (AI 9단계) — 코드만 다시 붙여넣기

`/ai/links` 가 추가됐습니다. **코드만** 바꾸면 됩니다 (Edit code → 전부 지우고 붙여넣기 → Deploy).

- 생각을 먹이면, 슬라임이 한마디 한 뒤 예전 기록(생각 · 답 · 메모 · 질문, 주제어가 겹치는 것 먼저 40개까지) 가운데 뜻이 이어지는 것을 0~2개 골라 첫 화면 말풍선으로 제안합니다.
- **이어 줘**를 누르면 두 기록이 이어지고 기록 지도에 주황색 굵은 선으로 나옵니다. **아니야**를 누르면 그 짝은 다시 제안하지 않습니다.
- 같은 낱말만 겹치는 것은 고르지 않게 했고, 확실하지 않으면 제안하지 않습니다.
- 다시 붙여넣기 전까지는 제안이 나오지 않습니다(앱은 그대로 동작).
- 비용: 먹일 때마다 한 번, 입력 2~4천 토큰 → 1원 안팎.
