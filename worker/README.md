# 도서 검색 중계소 — 설치 순서

책 제목으로 표지·저자·출판사를 찾아오기 위한 작은 중계소입니다.
카카오 열쇠를 공개된 `index.html`에 넣을 수 없어서 한 단계를 둡니다.

```
폰(기록장)  →  중계소(열쇠 보관)  →  카카오
```

기록(문장·질문·생각)은 여기를 지나가지 않습니다. **책 찾을 때 제목만** 나갑니다.

---

## 1. 카카오 열쇠 받기 · 5분

1. <https://developers.kakao.com> 접속 → 카카오 계정으로 로그인
2. 상단 **내 애플리케이션** → **애플리케이션 추가하기**
   - 앱 이름: `기록장`
   - 회사명: 아무거나 (본인 이름도 괜찮습니다)
3. 만들어진 앱을 누르면 **앱 키** 목록이 나옵니다
4. 그중 **REST API 키**를 복사해 둡니다

> 카카오 로그인이나 결제 같은 건 켜지 않아도 됩니다. 검색만 씁니다.

## 2. 중계소 만들기 · 10분

1. <https://dash.cloudflare.com> 가입 (무료)
2. 왼쪽 메뉴 **Workers & Pages** → **Create** → **Start with Hello World!**
   - 이름: `book-search` (주소가 `book-search.<계정>.workers.dev` 가 됩니다)
3. 만들어지면 **Edit code** 를 눌러 편집기를 엽니다
4. 안에 있던 예시 코드를 **전부 지우고**, 이 폴더의 `book-search.js` 내용을 붙여넣습니다
5. **Deploy** 를 누릅니다

## 3. 열쇠 넣기 · 2분

**코드에 열쇠를 적지 마세요.** 따로 보관합니다.

1. 그 Worker 화면에서 **Settings** → **Variables and Secrets**
2. **Add** → 종류는 **Secret**
   - 이름: `KAKAO_KEY`
   - 값: 1번에서 복사한 REST API 키
3. **Deploy** 로 반영

## 4. 잘 되는지 확인

브라우저 주소창에 이렇게 쳐 봅니다.

```
https://book-search.<계정이름>.workers.dev/?q=독서의 기술
```

책 목록이 JSON으로 나오면 성공입니다. 이 주소를 알려주시면 앱에 연결하겠습니다.

---

## 알아둘 점

- **열쇠는 저에게 주지 마세요.** 3번처럼 Cloudflare에 직접 넣으시면 됩니다. 저는 완성된 주소만 알면 됩니다.
- 같은 검색어는 하루 동안 중계소가 기억해 두고 씁니다.
- 앱 주소가 바뀌면 `book-search.js` 위쪽 `ALLOWED` 목록을 고쳐야 합니다.
- 표지 이미지는 카카오 서버에서 불러옵니다. 책을 책장에 넣을 때 한 번 받아 폰에 저장해두면, 그 뒤로는 밖으로 나가지 않습니다.
- 검색에 안 나오는 책(절판본·독립출판물)을 위해 **제목 직접 입력**과 **사진 고르기**는 그대로 남겨둡니다.
